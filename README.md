# 电池SaaS平台 - 毕业设计项目

> 基于Flask + Vue.js + 微信小程序的电池租赁管理系统

## 📋 项目简介

本项目是一个完整的电池租赁SaaS平台，支持多租户运营，包含Web管理后台和微信小程序端。用户可以通过小程序查找附近的换电站点、租用电池、查看订单等；管理员可以通过后台管理站点、电池、订单和用户。

## 💻 技术栈

### 后端
- **框架**: Flask 3.1.2
- **数据库**: SQLite (开发) / MySQL (生产)
- **ORM**: SQLAlchemy
- **认证**: JWT
- **缓存**: Redis (可选)

### 前端管理后台
- **框架**: Vue 3
- **UI组件**: Element Plus
- **状态管理**: Vuex
- **路由**: Vue Router
- **HTTP**: Axios

### 微信小程序
- **框架**: 微信原生框架
- **地图**: 高德地图API
- **支付**: 微信支付API

## 🚀 快速启动

### 方式一：Docker一键启动（推荐）

```bash
# 1. 启动所有服务
docker-start.bat

# 2. 访问系统
# 管理后台: http://localhost:8080
# 后端API: http://localhost:5000
```

### 方式二：本地开发启动

#### 后端启动
```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python run.py
```

#### 前端启动
```bash
cd frontend_admin
npm install
npm run serve
```

## 📊 数据库设计

系统包含16张核心数据表：

### 用户相关
1. **users** - 用户表（用户基本信息、余额、积分）
2. **tenants** - 租户表（多租户支持）
3. **admins** - 管理员表（后台管理员）

### 设备相关
4. **stations** - 站点表（换电站点信息、地理位置）
5. **cabinets** - 柜子表（电池柜信息、插槽状态）
6. **batteries** - 电池表（电池信息、状态、健康度）

### 业务相关
7. **orders** - 订单表（租用订单、费用计算）
8. **payments** - 支付表（支付记录、支付方式）
9. **packages** - 套餐表（租用套餐、价格策略）
10. **user_packages** - 用户套餐表（用户购买的套餐）
11. **exchange_records** - 换电记录表（换电历史）

### 系统相关
12. **operation_logs** - 操作日志表（管理员操作记录）
13. **system_configs** - 系统配置表（系统参数配置）
14. **wallet_transactions** - 钱包交易表（充值、消费记录）
15. **rbac_roles** - 角色表（权限管理）
16. **rbac_permissions** - 权限表（权限管理）

## 📱 小程序配置说明

### 开发环境配置
1. 下载并安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 打开微信开发者工具，导入项目目录：`frontend_mini`
3. 修改 `config.js` 中的API地址为你的后端地址
4. 编译运行

### API地址配置
```javascript
// frontend_mini/config.js
const config = {
  apiBaseUrl: 'http://localhost:5000/api',  // 本地开发
  // apiBaseUrl: 'https://your-domain.com/api',  // 生产环境
}
```

### 注意事项
- 小程序需要配置合法域名才能在真机上调试
- 开发阶段可以在开发者工具中勾选"不校验合法域名"
- 地图功能需要申请高德地图API密钥
- 支付功能需要配置微信支付商户号

3. **JWT认证的优势是什么？** - 无状态、跨域支持、可扩展性强
4. **如何保证支付安全？** - 微信支付签名验证、HTTPS传输、订单幂等性
5. **系统如何扩展？** - 微服务拆分、Redis缓存、数据库读写分离
6. **遇到的最大技术难点？** - 多租户数据隔离、微信支付集成、地图服务调用
