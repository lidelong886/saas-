# 石家庄真实换电站点导入

本项目提供 `backend/scripts/import_amap_stations.py`，用于通过高德地图 Web 服务 POI 搜索，把石家庄的换电站点导入 `stations` 表。

## 准备高德 Key

1. 登录高德开放平台，创建应用并添加 Web 服务 Key。
2. 在 PowerShell 设置环境变量：

```powershell
$env:AMAP_WEB_KEY = "你的高德Web服务Key"
```

## 预览导入结果

先不写库，只看会抓到哪些站点：

```powershell
cd C:\Users\lidelong\battery_saas_platform\backend
python scripts\import_amap_stations.py --city 石家庄 --limit 30
```

## 正式写入数据库

确认预览结果没问题后，加 `--commit`：

```powershell
cd C:\Users\lidelong\battery_saas_platform\backend
python scripts\import_amap_stations.py --city 石家庄 --limit 30 --commit
```

常用参数：

- `--limit 30`：最多导入 30 个去重后的站点。
- `--tenant-id 1`：导入到默认运营商。
- `--keywords "换电站,电动车换电,铁塔换电,e换电"`：自定义搜索关键词。

## Docker 方式

如果你用 Docker 运行后端，需要先重新构建镜像让新脚本进入容器：

```powershell
cd C:\Users\lidelong\battery_saas_platform
docker-compose up -d --build backend
docker-compose exec backend python scripts/import_amap_stations.py --city 石家庄 --limit 30 --commit --key 你的高德Web服务Key
```

## 小程序展示

小程序定位失败时的兜底坐标已改成石家庄市中心。导入成功后，在微信开发者工具重新编译小程序，打开地图/站点列表即可看到石家庄站点。
