# 毕设答辩检查清单

## 一、答辩前必须修复/确认

1. **核心流程可完整演示**
   - 用户注册、登录、查看个人信息。
   - 查看附近站点、站点详情、地图定位。
   - 购买/启用套餐，展示当前套餐状态。
   - 扫码租电、查看当前电池、电量预估。
   - 换电流程：选择站点、选择新电池、确认换电、生成换电记录。
   - 余额充值、余额支付、订单列表、订单详情。
   - 故障上报、通知查看。

2. **演示环境配置说明**
   - `frontend_mini/config.js` 中的 cpolar/LAN 地址属于演示环境配置，不作为本次修复项。
   - 答辩前确认后端服务、数据库、内网穿透地址均可访问。
   - 小程序真机调试时确认 request 合法域名或开发工具“不校验合法域名”配置。

3. **演示模式说明**
   - 支付功能为“毕设演示模式”：余额支付完成真实扣款与订单状态流转，第三方微信/支付宝支付保留预支付与回调扩展点。
   - 实名认证为“毕设演示模式”：提交后展示实名状态，生产环境可对接公安实名核验或人工审核。
   - 答辩时主动说明：演示模式用于展示业务闭环，不等同生产支付/实名能力。

4. **安全与一致性**
   - 密码规则统一：至少 8 位，且包含字母和数字。
   - 不在前端日志打印微信登录 `code`、token、密码等敏感信息。
   - 生产环境必须配置 `SECRET_KEY`、`JWT_SECRET_KEY`、`DATABASE_URL`、`CORS_ORIGINS`、`AMAP_KEY`。
   - 开发环境允许便捷配置，但答辩说明中要区分开发环境和生产环境。

## 二、建议测试接口

| 模块 | 接口 | 测试重点 |
| --- | --- | --- |
| 认证 | `/api/v1/auth/register`、`/api/v1/auth/login` | 手机号、用户名、密码强度、token 返回 |
| 用户 | `/api/v1/user/profile`、`/api/v1/user/stats`、`/api/v1/user/balance` | 余额、当前套餐、当前租用电池 |
| 站点 | `/api/v1/station/nearby`、`/api/v1/station/<id>` | 距离、可用电池数、租户隔离 |
| 套餐 | `/api/v1/package/list`、`/api/v1/user-package/list` | 套餐购买后状态展示 |
| 电池 | `/api/v1/battery/scan/<code>`、`/api/v1/battery/<id>/rent` | 扫码租电、状态流转 |
| 换电 | `/api/v1/exchange/*` | 站点选择、电池选择、换电记录 |
| 支付 | `/api/v1/payment/pay`、`/api/v1/payment/recharge` | 余额扣款、订单状态、充值记录 |
| 故障 | `/api/v1/fault-report/*` | 上报、列表、状态 |

## 三、建议测试页面

- 小程序：首页普通模式、首页送单模式、换电页、地图页、套餐页、订单页、余额页、实名认证页、故障上报页。
- 管理后台：登录页、仪表盘、用户管理、站点管理、电池管理、订单管理、租户/权限相关页面。

## 四、答辩老师可能追问

1. **为什么叫 SaaS？**
   - 回答要点：系统有租户字段、租户隔离、后台租户管理、不同租户可独立管理站点/电池/用户数据。

2. **支付和实名认证是否真实？**
   - 回答要点：当前是毕设演示模式；余额支付和订单状态流转是真实业务逻辑；第三方支付/实名预留接口和扩展点。

3. **如何保证数据安全？**
   - 回答要点：JWT 鉴权、管理员权限控制、租户隔离、密码哈希、生产环境强制密钥与 CORS 配置。

4. **如何保证系统可靠？**
   - 回答要点：订单状态机、余额流水、异常提示、核心接口测试、Docker/本地双启动方式。

5. **系统创新点是什么？**
   - 回答要点：骑手送单模式、电量续航预估、附近站点推荐、租售换一体化、SaaS 多租户后台。

## 五、答辩演示顺序建议

1. 管理后台登录，展示仪表盘和基础数据。
2. 展示租户、站点、电池、套餐管理。
3. 小程序登录，切换普通/送单模式。
4. 展示电量卡片、附近站点推荐和地图导航。
5. 演示扫码租电或换电完整流程。
6. 演示余额充值/支付、订单和换电记录。
7. 最后说明演示模式、生产扩展点和安全配置。
