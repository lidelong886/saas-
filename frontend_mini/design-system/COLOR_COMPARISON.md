# 配色方案对比

> 新旧配色对比，一目了然

---

## 🎨 配色变化总览

### 旧配色方案（混乱）

```
首页普通模式：
  主色：#64748B（灰色）
  强调：#F97316（橙色）
  背景：#F8FAFC（浅灰）

首页送单模式：
  主色：#00ff88（荧光绿）❌ 太刺眼
  背景：#1a1a1a（纯黑）❌ 对比度过高

换电页面：
  主色：#4f46e5, #6366f1（紫色）❌ 与品牌不符
  渐变：#4f46e5 → #7c3aed

电池列表：
  主色：#0f172a（深蓝黑）
  强调：#10b981（绿色）
  背景：#f4f6f9（浅灰）
```

**问题：**
- ❌ 4种不同的配色方案
- ❌ 荧光绿 #00ff88 太刺眼
- ❌ 紫色 #4f46e5 与品牌不符
- ❌ 纯黑背景 #1a1a1a 对比度过高
- ❌ 用户体验不一致

---

### 新配色方案（统一）

```
所有页面统一：
  主色：#2563EB（信任蓝）✅
  强调：#F97316（行动橙）✅
  成功：#10B981（可用绿）✅
  警告：#F59E0B（警告黄）✅
  危险：#EF4444（危险红）✅
  背景：#F8FAFC（浅灰）✅
```

**优势：**
- ✅ 统一的配色方案
- ✅ 蓝色传递信任感
- ✅ 橙色引导行动
- ✅ 清晰的状态层级
- ✅ 符合无障碍标准

## 🎯 使用场景对比

### 主色调

**旧方案：**
```css
/* 首页 */
color: #64748B;

/* 换电页面 */
color: #6366f1;

/* 电池列表 */
color: #0f172a;
```

**新方案：**
```css
/* 所有页面统一 */
color: var(--primary);  /* #2563EB */
```

---

### 强调色（CTA）

**旧方案：**
```css
/* 所有页面 */
background: #F97316;  /* 橙色 - 保持不变 ✅ */
```

**新方案：**
```css
/* 所有页面统一 */
background: var(--cta);  /* #F97316 */
```

---

### 成功/可用状态

**旧方案：**
```css
/* 首页送单模式 */
color: #00ff88;  /* 荧光绿 - 太刺眼 ❌ */

/* 其他页面 */
color: #10b981;  /* 标准绿 ✅ */
```

**新方案：**
```css
/* 所有页面统一 */
color: var(--success);  /* #10B981 */
```

---

### 背景色

**旧方案：**
```css
/* 首页普通模式 */
background: #F8FAFC;

/* 首页送单模式 */
background: #1a1a1a;  /* 纯黑 - 对比度过高 ❌ */

/* 换电页面 */
background: #f0f2f8;

/* 电池列表 */
background: #f4f6f9;
```

**新方案：**
```css
/* 所有页面统一 */
background: var(--gray-50);  /* #F8FAFC */

/* 送单模式深色背景 */
background: var(--gray-900);  /* #0F172A - 深灰而非纯黑 */
```

## 📐 对比度检查

所有颜色组合均通过 WCAG AA 标准（4.5:1）：

| 前景色 | 背景色 | 对比度 | 状态 |
|--------|--------|--------|------|
| `#334155` (gray-700) | `#FFFFFF` | 9.73:1 | ✅ AAA |
| `#64748B` (gray-500) | `#FFFFFF` | 5.05:1 | ✅ AA |
| `#94A3B8` (gray-400) | `#FFFFFF` | 3.08:1 | ⚠️ 仅大文字 |
| `#2563EB` (primary) | `#FFFFFF` | 4.56:1 | ✅ AA |
| `#F97316` (cta) | `#FFFFFF` | 3.37:1 | ⚠️ 仅大文字 |
| `#FFFFFF` | `#2563EB` (primary) | 4.56:1 | ✅ AA |
| `#FFFFFF` | `#F97316` (cta) | 3.37:1 | ⚠️ 仅大文字 |

**注意：**
- ✅ 标题和正文文字使用 gray-700 或更深
- ⚠️ 橙色按钮使用白色文字（大文字，符合标准）
- ✅ 次要文字使用 gray-500 或更深

## 🚀 迁移建议

### 优先级 1：立即替换
- ❌ `#00ff88` → ✅ `var(--success)`
- ❌ `#4f46e5`, `#6366f1` → ✅ `var(--primary)`
- ❌ `#1a1a1a` → ✅ `var(--gray-900)`

### 优先级 2：逐步替换
- 所有硬编码颜色 → CSS 变量
- 不统一的圆角 → `var(--radius-md)`
- 不统一的按钮高度 → `var(--btn-height)`
